**Verification limit:** no tests, builds, or runtime checks were run. A requirement ID in code is only a traceability marker, not proof its behavior is complete. Every item remains runtime-unverified until its acceptance path is executed.

## Status definitions

- **Source reference found; behavior/runtime unverified:** requirement ID appears in a source or test file. Review the listed locations; do not infer completion from the marker.
- **No source reference found; runtime unverified:** no exact requirement ID appears in scanned source files. This is a missing traceability signal, not proof the feature is absent.
- Runtime acceptance uses the criterion from the SRS or the end-to-end/security scenarios in the approved plan.

## Cross-system acceptance scenarios

1. OAuth identity ? GitHub App installation/repository access ? baseline indexing at an immutable commit.
2. Generate by file, module/package, and repository; retain code links, commit grounding, confidence, and template validation.
3. Source PR create/update/close-unmerged: verify webhook HMAC, delivery idempotency, async correlation, AST + RAG/LLM evidence, PR comment/status, source-linked update lifecycle, and retry/DLQ.
4. Developer ? Staff ? Manager with distinct people; reject author self-approval and Staff/Manager same-person approval; preserve audit trail and immutable versions.
5. Manager approval ? publish attempt ? merged webhook; only a successful target commit or verified PR merge may set Published. Test stale code snapshot, failed/closed documentation PR, and retry.
6. Verify tenant-crossing requests are denied, repository disconnect revokes access and redacts content while preserving verifiable audit metadata, and secrets never reach logs or unmasked model inputs.
7. Exercise mobile OAuth PKCE, role-appropriate review actions, push registration/revocation, and shared server-side authorization.
8. Measure the SRS performance, availability, backup/restore, drift precision/recall, regex-baseline comparison, and core logic coverage targets on a configured environment.
